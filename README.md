# Coditas Skills Radar

## Project Overview

This project is developed as part of INFS2603 Business Analysis and Agile Product Management at UNSW.

The project addresses challenges faced by Coditas in retaining project knowledge and improving visibility of employee skills across the organisation.

Current issues identified include:

- Knowledge loss after project completion
- Limited visibility of employee skills and expertise
- Slow onboarding of engineers to new projects
- Dependence on informal communication channels
- Difficulty matching employees to suitable projects

Our proposed solution is **Skills Radar**, a digital platform that centralises employee skills, project knowledge, and expertise visibility to improve staffing decisions and knowledge sharing.

---

## Product Vision

Provide engineers and managers with fast and reliable access to organisational skills and project knowledge so that teams can form more effectively and reduce onboarding time.

## Enterprise Analysis

To understand the organisational problem, several business analysis frameworks were applied:

### External Analysis

- Industry analysis

- Economic impact analysis

- Human capital assessment

- Competitive pressure analysis

### Internal Analysis

- POPIT Analysis

    - People

    - Organisation

    - Process

    - Information

    - Technology

### Stakeholder Analysis

Key stakeholders identified:

- Engineers

- Project Managers

- HR Team

- Senior Management

- Clients

Methods used:

- Stakeholder categorisation

- Influence-interest matrix

- Stakeholder needs analysis

### Root Cause Analysis

Root causes identified:

- Skills not visible for decision making

- Skills not captured and maintained

- Reliance on tacit knowledge

- Manual and inconsistent skill updates
